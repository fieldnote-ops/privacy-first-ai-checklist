# Privacy-first automation handoff preflight

**自动化项目交付预检 / Client automation handoff preflight**

A free, experimental 15-minute check for freelancers and small teams that recently delivered a client automation. It helps make five handoff questions answerable:

- Who owns the instance, billing, and recovery path?
- Who controls, rotates, and revokes each connection?
- Which actions require approval?
- Which version and failure path were actually tested?
- When and how does builder access end?

[Run the bilingual preflight](https://fieldnote-ops.github.io/privacy-first-ai-checklist/)

## Privacy boundary

No account, analytics, cookie, backend form, or free-text upload. Use fictional or fully redacted data. The receipt is generated locally in the browser and leaves the device only if the participant chooses to share it.

## Evidence boundary

This is a demand test, not a proven product. A public page, download, or GitHub visit does not prove usefulness or willingness to pay. It is not a contract, security review, n8n template, or substitute for platform-specific documentation.
